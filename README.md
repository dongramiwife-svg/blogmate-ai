# BlogMate AI v0.9 — 갤럭시 일괄 댓글 준비

## 변경점
- RSS 게시글마다 댓글 초안 자동 준비(무료 제목 기반 템플릿, AI 아님)
- 선택한 댓글 일괄 복사, 다음 선택 글 열기, 댓글/공감 완료 체크
- 초안/선택/완료 상태는 갤럭시 브라우저 localStorage에 저장
- GitHub Pages에서 실제 접근 가능한 `docs/latest.json`으로 수집 결과 공개 경로 수정
- 기존 Firebase 웹 푸시 구성 유지, 텔레그램 없음

## 배포
1. 갤럭시 Chrome에서 GitHub에 로그인하고 공개 저장소에 이 폴더의 파일들을 업로드합니다.
2. `data/feeds.json`에 RSS를 공개하는 네이버 블로그 ID를 등록합니다.
3. Settings → Pages에서 `main` 브랜치 `/docs`를 게시합니다.
4. Actions 탭에서 `BlogMate RSS check`를 수동 실행해 기준선을 생성합니다. 이후 예약 실행을 확인합니다.
5. Firebase 알림을 쓰려면 기존 v0.8 README의 Firebase Spark 설정 및 GitHub Secret 구성이 추가로 필요합니다. 서비스 계정 비밀 키는 절대 공개 저장소에 넣지 마세요.
6. 갤럭시 Chrome에서 Pages URL을 열고 홈 화면에 추가합니다.

## 제한
- 네이버 계정 이웃 전체 조회는 공식 API가 없어 지원하지 않습니다. 공개 RSS 목록만 감시합니다.
- 자동 댓글 등록/자동 공감은 하지 않습니다. 댓글 복사 후 네이버에서 직접 등록하세요.
- '완료'는 사용자가 수동 체크한 상태로 실제 등록 성공 여부와 연동되지 않습니다.
- GitHub Actions 예약 실행은 지연/누락될 수 있습니다. 08:00 정확한 실행을 보장하지 않습니다.
- 무료 템플릿은 게시글 본문을 이해하지 않으며, 사용자가 검토해야 합니다.
- 공개 저장소에 등록 블로그 목록과 게시글 제목이 공개됩니다.
- 브라우저 저장소 삭제 시 댓글 초안과 완료 체크가 사라질 수 있습니다.
- 실제 GitHub/Firebase/갤럭시 실서비스 통합 테스트는 아직 수행하지 않았습니다.
